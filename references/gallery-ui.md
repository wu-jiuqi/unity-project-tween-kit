# 0.2.0 展馆操作流程

参考用户指定的[碰撞反馈展馆](https://github.com/wu-jiuqi/unity-2d-impact-feedback/tree/807ace626a9f2c292d0ac42180cc6d4e72c8aa0e)：三区布局、原生UGUI控件、明确操作入口、中文参数与精确数值输入。舞台继续调用同一套ProjectTweenKit组件；没有另造一套演示算法或新增美术。

## 体验一项效果

1. 左侧选“效果体验”。搜索、使用场景和动画类型可组合筛选；上一项/下一项在筛选结果内切换。
2. 中间先看绿色操作提示。按压、开关、欢迎语拖拽和活动卡直接操作舞台；弹窗、收集、滚分、受击和充星从固定的主动作按钮触发。
3. 入场、加载、序列帧和结算按原方式自动播放。可重新开始、暂停/继续，并使用0.25×、0.5×、1×观察速度。时间轴只显示在具备真实采样能力的效果中。
4. 右侧默认是“调参数”：中文名称、单位、滑条和精确输入。更改保留在当前条目，重新开始也保留。恢复默认只恢复当前项。
5. “保存本项/载入本项”使用原MotionPreset格式；“参数目录”打开JSON文件夹。支持的条目提供即时完成对照，下一次触发时生效。

切换条目会清除上一项操作反馈，并解除暂停，避免出现新效果停住而不知原因。手动效果不会在切换时伪造一次点击。

## 查看细节和接入

- “放大舞台”提供更大的操作区域；“返回调参”保留当前示例与参数。
- “接入说明”单独显示触发、绑定、时序、类和源文件，避免把实现信息塞进默认体验流程。
- 从接入说明可定位到来源档案；已有关联演示的记录可返回对应效果。
- “来源档案”是独立的只读浏览模式。进入时隐藏并停止当前舞台，防止一边选未提取来源、一边仍播放上一项效果。
- 长目录、参数和说明都有滚动条；窗口变化时整个界面等比缩放。
- 空格触发当前主动作，P暂停/继续，R重新开始。编辑搜索或数值时，快捷键不会触发演示。

## 代码与验证

`Gallery.cs`负责示例装配与表现接口；`GalleryUI.cs`负责原生界面、输入提示、参数面板与档案导航。底层`assets/unity-kit/Runtime`保持同源。

运行检查除原组件生命周期外，增加原生主动作、搜索空态、条目切换清理、档案隔离与返回、充星连续操作、单项默认值恢复和放大舞台返回。最终原生窗口核对布局、点击和弹窗完整开关流程；最终精确键盘输入核对因窗口最小化及输入保护中断，未计为通过。实际证据范围见`evidence/visual-checks.json`。

这次是展馆流程与界面升级；全项目动画整理范围和未完成来源核对仍以`acceptance.json`为准。
