# 0.3.0 展馆操作流程

展馆面向后续项目复用动画设计。使用原生UGUI三栏界面，舞台直接调用随包组件，右侧提供动画Prompt及当前参数。已移除来源档案、源码定位和接入说明页签。

## 体验并带到新项目

1. 左侧搜索或按使用场景、动画类型筛选26项效果。
2. 先读中间绿色操作提示。按压、开关、拖拽直接操作舞台；计分、收集、评价等点击固定主动作。入场和装饰按原方式自动运行。
3. 右侧“调参数”提供中文单位、滑条、精确输入；计分高亮支持#RRGGBBAA颜色。可恢复当前项默认或保存/载入JSON。
4. 切到“动画 Prompt”，阅读效果目标、触发方式、关键参数写法、当前实调值及中断规则。
5. 点击“复制 Prompt 与当前参数”，粘贴到新项目的AI对话中。要求沿用新项目的视觉风格和素材；复用组件名用于接入，不需要定位原项目源码。

Prompt按本项实时生成，调参后再次复制会带出新值。没有公开参数的固定编排也提供关键时间、曲线及需要适配的部分，不把观察速度当成组件参数写出。JSON存的是同类型组件参数，对象引用仍由宿主绑定。

## 控制

- 放大舞台与返回调参保留同一轮演出、对象和参数。
- 重新开始、暂停/继续、0.25×/0.5×/1×用于观察。
- 具备真实采样接口的条目显示时间轴，适用条目可即时完成对照。
- 空格触发主动作，P暂停，R重新开始；编辑输入框时不触发全局快捷键。
- 交互只提交本地演示输入；重播不发奖、不导航、不写存档。

## 新增的7项

分数变金放大、加分合并上浮、目标到达和完成印章、剩余步数挤压、连击评价星光、排行卡果冻抖动、背景平滑换景。分数脉冲和加分提示另有独立预制体；各项的可运行组件、默认参数和Prompt都随包提供。
