# 0.4.0 展馆操作流程

展馆用于在后续项目复用动画设计。36个条目直接调用随包组件，使用项目现有素材。右侧为“调参数”和“参数显示”，不包含AI Prompt、源码定位或来源档案。

1. 左侧搜索、按使用场景或动画类型筛选。
2. 按绿色提示体验：按压/开关/拖拽直接操作舞台；计分、收集、页面切换等使用固定主动作；装饰循环和入场按原时机播放。
3. 在“调参数”中用滑条或精确输入调整；数值标明单位，颜色采用#RRGGBBAA。
4. “参数显示”列当前生效字段、固定曲线基准、时间来源与组件类型。
5. 点击“一键复制参数导出”：剪贴板获得JSON，同时写入`Application.persistentDataPath/presets/<条目>.json`。切回“调参数”可点“参数目录”。

导出JSON兼容原MotionPreset读取器。`settings`承载可应用的当前参数；`referenceParameterNotes`只是固定常量/曲线的核对说明，修改它不会修改运行代码。对象引用、业务状态和展馆观察倍速不导出。[参数格式与接入](integration.md)。

放大舞台和返回调参保留当前组件与进度。重新开始保留调参；恢复默认只影响当前项。空格触发主动作，P暂停，R重新开始；编辑输入框时快捷键暂停。时间轴仅在可采样条目中显示。

## Loading体验

搜索Loading可见独立果冻进度条与完整微信启动页。主动作模拟一批任务进度+20%；舞台内“任务完成”发送真实宿主应给出的完成信号，“模拟中断/恢复加载”验证保持，“重置进度”开始新一轮。示例不访问网络。

装饰动画持续运行不代表真实任务在推进；收到进度输入后才追赶，完成信号前最多99%。所有文字、进度与弹珠位置使用同一个显示值。完整启动页按原竖屏比例展示，可点“放大舞台”。
